## 🎯 Présentation
Tableau de bord en temps réel conçu pour un écran secondaire ou une tablette. Affiche la météo (OpenWeather), les prévisions, et un lecteur musique avec paroles synchronisées. Design glassmorphism.

---

## ✨ Fonctionnalités
- ✅ Météo et prévisions en temps réel
- ✅ Lecteur musique avec paroles synchronisées
- ✅ Notifications push
- ✅ Cache intelligent (gzip)
- ✅ Design glassmorphism

---

## 🚀 Installation
```bash
git clone https://github.com/MattiaPARRINELLO/tab-screen.git
cd tab-screen
npm install
cp .env.example .env
npm start
```
